**Full description (en)**

```
Liyamu (ලියමු, "let's write") is a Sinhala keyboard that keeps what you type to yourself.

PRIVATE BY DESIGN
• No internet permission. The app cannot send anything anywhere.
• Voice typing: a microphone key opens your phone's own voice typing (Sinhala included). Liyamu itself has no microphone permission.
• No account, no ads, no analytics, no tracking.
• Learns the words you pick and the words you usually write next, on your phone only: nothing you type goes anywhere, and you can switch it off or delete it. Passwords are never looked at.
• Open source, so anyone can check.

FREE, ALL OF IT
No premium version, no paid features, no strings attached.

TYPE THE WAY YOU LIKE
• Easy Singlish – type as you would in a chat and pick the word: mama gedara yanawa → මම ගෙදර යනවා
• Wijesekara – the standard Sri Lankan layout, with the extra letters on a long press
• Helakuru keys – exact phonetic typing with the keys you already know
• English – the globe key changes between Sinhala and English, without changing keyboards
• Emoji, numbers on a long press, and next-word suggestions after every word

SUGGESTIONS THAT ARE REAL WORDS
• Only real Sinhala words are offered, from a list of about 146,000
• Leave the vowels out: hri ennm → හරි එන්නම්, gdr → ගෙදර, khmd → කොහොමද
• Small slips are fixed: gedar, gedra → ගෙදර
• Common misspellings are corrected to the dictionary spelling: පුලුවන් → පුළුවන්
• About 10,000 Sri Lankan place names and common names: homagama → හෝමාගම, col → කොළඹ
• The previous word is taken into account
• Your own shortcuts: bs → බුදු සරණයි

FOR PALI AND DHAMMA BOOKS
• Repaya, joined letters (බැඳි අකුරු) and touching letters as options
• Pali words in the suggestions when you want them

Liyamu is made by the Path Nirvana Foundation, the makers of arutha.lk and pitaka.lk, and grew out of the
Akkharapadayo typing tool by Ven. M. Pagngnaseeha Thero.

Android shows a warning for every keyboard that it "may be able to collect all the text you type". Liyamu
has no way to send it anywhere.
```

## macOS (GitHub release)

```
Liyamu for macOS – a private, free Sinhala keyboard

• Wijesekara, Easy Singlish and Helakuru keys in one input method (choose in its menu)
• Types Unicode, or FM / Isi codes for documents in the old fonts
• Real-word suggestions with typo and shorthand correction; → ← to choose, Space to take
• Settings and Help window: repaya, Pali joined and touching letters, Pali words, your own shortcuts
• Learns the words you pick, on this Mac only (can be turned off or deleted)
• No network access

Install: open the .pkg, then add Liyamu in System Settings › Keyboard › Text Input › Input Sources › + ›
Sinhala. If it is not listed, log out and in once.
```
